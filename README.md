# Space Arenas — RTS Game

A browser-based real-time strategy game inspired by *Command & Conquer: Generals*. Build a base, harvest supplies, manage power, train an army and destroy every enemy Command Center — solo, with AI bots, or online with friends.

[**Play it now**](https://github.com/SDevRami/space-arenas) — clone, run `run-game.bat`, and start a match straight in your browser. The single-page landing site (game overview, unit roster, how-to-join, full game catalog) and the separate Community hub (mods) live at **[https://sdevrami.github.io/space-arenas](https://sdevrami.github.io/space-arenas)**.

The project is **finished and shipped**: the classic LAN client, the online server (`online/`), the GitHub Pages landing page, account system, balance-mod community repository, encrypted progress backups and local replay saves are all live and verified.

## What's in the game

- **Dual-resource economy** — Supplies (income from Harvesters and supply fields) + Power (generated by plants, consumed by buildings; deficits shut production down).
- **Full build tree** — 11 buildings, 13 units, 9 weapons and 12 research upgrades, all in the in-game catalog and on the [landing page](https://sdevrami.github.io/space-arenas/).
- **Vision systems** — fog of war (memory / classic / hard modes), stealth + detectors, satellites, day/night cycle and weather (rain, snow, thunderstorms).
- **Combat depth** — turrets, bunkers, AA platforms, artillery splash, sea missiles, transports (APC/carrier), vehicles that crush infantry, mines, grenades & smoke, and rank-gated Super Weapons (Space Laser, Airstrike, EMP).
- **Progression** — unit veterancy, player XP/levels, commander ranks (★), daily mission lists and profile achievements.
- **Content tools** — procedural maps, a built-in map builder (paint/edit/import/export), bot AI at 3 difficulties, teams, spawn assignment and off-map naval play.
- **Online** — password-protected rooms, match browser, accounts, global leaderboard, encrypted backups, local replay-file saves and tamper-watch verification on ranked matches (see `docs/12`).
- **Mods** — economy/unit/weapon balance via JSON mod files, import/export in-game, and a community repository on the landing page with ratings and download counts.
- **i18n** — full English and Arabic (RTL) support in the client and the landing page.

## Getting Started

### Play locally (offline)

```bash
git clone https://github.com/SDevRami/space-arenas
npm install
npm run dev        # Starts Vite dev servers + the LAN host server
```

Or, **without any install**, double-click `run-game.bat` (Windows) — it boots a minimal local server and opens the game in your browser.

### Play online

Host or join a room in the game's online lobby (the client connects to `space-arenas-online.onrender.com`). Sign up for a free account to unlock the leaderboard, encrypted progress backups, the balance-mod repository and replay saves.

> **Note:** the client defaults to the public online server. To run your own instance, set the server address at build/runtime via env (see `online/.env.example` and `render.yaml`) — no secrets are committed.

## Developing / Running the Online Server

The `online/` service is a Node + Express app deployed on Render, using Supabase Postgres for persistence. Local development:

```bash
cd online
npm install
# create .env from .env.example: SA_MODE=local, plus your Supabase keys
npm run dev
```

GitHub Actions deploys `online/public` to GitHub Pages automatically on every push that touches it.

```bash

                  #   economy, oil, mines, crush, transport, veterancy, sea army, …

npm run typecheck # Type-check all workspaces (shared/client/host/mapbuilder)
cd online && npm test  # Online API suite (31 tests) + build/typecheck
```

Current state: **400+ Vitest tests, 19 protocol round-trip tests, 31 online API tests** all green; the client and online services build and typecheck clean.
